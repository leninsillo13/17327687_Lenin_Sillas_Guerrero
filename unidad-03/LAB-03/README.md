# LAB-03 — Políticas prácticas, gobierno de datos y evidencias

Materia: Gestión de Seguridad y Desempeño de Bases de Datos — Unidad III.
Entregable oficial de la unidad: **`EXPEDIENTE.md`** (configuración de auditoría con bitácora interpretada).

## Contenido

| Carpeta o archivo | Qué contiene |
|---|---|
| `EXPEDIENTE.md` | Expediente de auditoría interna (10 secciones y anexo) |
| `politicas/` | POL-01 a POL-06 |
| `sql/` | 01 calidad, 02 comentarios, 03 inventario, 04 registro de cambios y bitácora histórica |
| `evidencias/01` a `06` | Calidad, responsables, diccionario, catálogo, conservación, conciliación (con evidencias técnicas) |
| `evidencias/E1` a `E6`, `diccionario-clientes.csv` | Evidencias técnicas con hash SHA-256 |

## Notas

- PostgreSQL 18.6 en Windows (la guía asume 16); los mensajes del servidor están en español.
- Los registros 7 y 8 de `clientes` se conservan a propósito como hallazgos.
